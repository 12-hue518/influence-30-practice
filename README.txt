今回反映した仕様
1. 名称：『影響力の正体』30の実践チャレンジ
2. 1つ目では「はじめに」を開いて表示し、2つ目以降は自動で折りたたみ
3. 30項目を一覧表示せず、1つ完了すると次の1つがアンロック
4. 過去の項目は「完了した実践」から見返せる
5. 4 SECTION構成
   SECTION 01：自分と相手が動き出す「土台」をつくる（1〜8）
   SECTION 02：「伝わり方」と言葉を整える（9〜15）
   SECTION 03：人が自然と動く「しくみ」をつくる（16〜23）
   SECTION 04：影響力を守り、信頼を広げる（24〜30）
6. SECTION完了時は紙吹雪・COMPLETE表示・解放表示つきのお祝いポップ。何ができるようになったかも返す
7. 5 / 10 / 15 / 20 / 25 / 30達成時に大きな達成ポップ
8. 達成画像を1080×1350 PNGで保存可能。共有シート対応、LINE等では長押し保存用フォールバックを表示
9. 達成画像は青・白・ピンク・黒＋確定書影で統一
10. 達成画像の下段コピーは節目ごとに変更
11. 各実践の「詳しくは書籍で」を大幅に削減。BOOK NOTEは3か所だけに絞り、書籍への答え合わせは主にSECTION完了時へ集約
12. 旧バージョンの進捗は一切引き継がず、v8では初回0 / 30から開始

達成画像コピー
5：想いは、伝え方ひとつで届きはじめる。
10：「なぜか伝わる人」には、理由がある。
15：人を動かす力は、才能ではなく技術。
20：言葉だけでなく、しくみでも人は動く。
25：影響力は、誰かを動かす前に、自分を整えることから。
30：その魅力や価値が、必要な人に届くように。

GitHub Pages更新手順
1. GitHubの対象リポジトリを開く
2. 今回のフォルダ内のファイルを、同じ階層構造でアップロード
3. 既存の index.html / manifest.json / sw.js は置き換える
4. assets フォルダと icons フォルダもアップロード
5. commit
6. Pages反映後、スマホで確認

更新が反映されない場合
- sw.js の CACHE_NAME を v6 などに変更してcommitすると、古いキャッシュを強制的に切り替えやすいです。
- ホーム画面追加済みの場合、一度アプリを完全終了して開き直してください。
